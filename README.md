A single hilarious one-liner for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty on make.fun.

Run with Node 22:

```
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

The program writes one funny line (at most 200 characters, exactly one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
